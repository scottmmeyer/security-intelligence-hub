## 4. Design Specification

### 4.1 New `operational_state` Value

**Add:** `ZERO_VALUE_LEGACY_POSITION`

**Definition:** A holding with `market_value = 0.0` that is a broker-internal bookkeeping artifact (contra lot, fractional residual, settlement stub) with no economic value and no intended future trades. The position is retained in the portfolio data feed for broker reconciliation purposes only.

**Distinguishes from:**
- `ACTIVE_POSITION` — economically meaningful, actively managed
- `CASH_EQUIVALENT` — cash position, positive market value
- `STRATEGIC_HOLD` — held below target, retained intentionally

### 4.2 New `security_type` Value

**Add:** `CONTRA_ENTRY`

**Definition:** A broker-generated bookkeeping entry resulting from corporate action reconciliation (mergers, splits, tender offers). Not a tradeable security. Typically $0.00 market value.

**Why not `ETF`:** Classifying M26CNT069 as ETF triggers the ETF exposure decomposition pipeline, which runs HEURISTIC_FALLBACK on a $0.00 artifact and produces a meaningless decomposition with `confidence=0.35`. This is wasted compute and misleading in governance logs.

### 4.3 Ingestion Auto-Classification

**In `src/portfolio/ingestion.py` or enrichment pipeline:**

```python
_CONTRA_SYMBOL_PATTERN = re.compile(r'^M\d{2}CNT\d+$')

def _classify_zero_value_position(symbol: str, description: str, market_value: float) -> dict | None:
    """Returns operational_state/security_type overrides if position is a zero-value legacy artifact."""
    if market_value != 0.0:
        return None
    if _CONTRA_SYMBOL_PATTERN.match(symbol) or 'CONTRA' in (description or '').upper():
        return {
            'operational_state': 'ZERO_VALUE_LEGACY_POSITION',
            'security_type': 'CONTRA_ENTRY',
        }
    return None
```

**Classification criteria (ANY condition triggers):**
1. `market_value == 0.0` AND symbol matches `^M\d{2}CNT\d+$`
2. `market_value == 0.0` AND description contains "CONTRA" (case-insensitive)

The `market_value == 0.0` guard prevents the pattern from misclassifying legitimate contra-named instruments if they ever carry non-zero value.
