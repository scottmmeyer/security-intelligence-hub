## 1. CW-DAS Capital Deployment Queue (DQ)

**Source:** `src/portfolio/deployment_queue.py` — `build_deployment_queue()`  
**Artifact:** `deployment_queue.json` → `dq_payload.queue`

| Attribute | Value |
|---|---|
| Action types generated | BUY / ACCUMULATE only |
| Ranking method | CW-DAS score (0–100+), described below |
| Eligibility gate | signal_direction == BULLISH, replay_supported == True, strategic_classification == HIGH_CONVICTION_RETAIN, narrative_tier in {CCL, HCA} |
| Policy filtering | DO_NOT_SELL → removed from queue + placed in policy_suppressed; SELL_LAST → ranked last within sell cohort |
| Operator visibility | Full table in Deployment Queue section; Top 10 shown in "Recommended Actions — Top 10" action cards |
| Sell/Trim eligibility | **None.** BEARISH signal_direction is a hard eligibility exclusion (line 414 of deployment_queue.py) |
| RPS (Reduction Priority Score) | Not computed or used |

**CW-DAS Formula:**
```
score = signal(0-30) + replay(0-20) + conviction(0-35) + sizing(0-8) + momentum(0-10) + fund_mod(-5 to +3) - redundancy_pen(0-15) - conc_pen(0-20)
```

Where `signal = min(composite/5.0*30, 30)`, `replay = 20 if replay_supported else 0`, `conviction = 35/28/10` for CCL/HCA/other tier.

**Current queue:** 31 entries (all CCL/HCA, all BULLISH, all replay_supported).
