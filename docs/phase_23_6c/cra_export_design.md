# CRA Export Design — Phase 23.6C

## Export Formats

### A — CSV Export

**Endpoint:** `GET /api/cra/draft/export?format=csv`  
**Filename:** `cra_proposal_{as_of_date}.csv`  
**Content-Type:** `text/csv`

Two-section CSV (sources then targets):

**Sources section:**
```
section,symbol,category,priority,estimated_proceeds,sizing_pct,tax_bucket,evidence_summary
SOURCE,CVE,SIGNAL_DETERIORATION,HIGH,12450.00,0.5,C,Very Bearish ESS...
...
```

**Targets section:**
```
section,rank,symbol,narrative_tier,deployment_score,suggested_amount,projected_weight_pct
TARGET,1,DELL,CORE_CONVICTION_LEADER,99.33,8750.00,3.2%
...
```

**Impact section (single row):**
```
section,alignment_before,alignment_after,delta,concentration_before,concentration_after,narrative
IMPACT,62.5,65.2,+2.7,38.1,35.8,Rotation improves alignment by ~2.7 points...
```

**Endpoint:** `GET /api/cra/draft/export?format=md`  
**Filename:** `cra_proposal_{as_of_date}.md`  
**Content-Type:** `text/markdown`

**Content:** Plain text suitable for advisor meeting notes or investment journal
