# Benchmark Philosophy

## Purpose

Benchmark context anchors signal interpretation and outcome analysis. The
platform maintains deterministic benchmark mappings so provider signals can be
evaluated in comparable market context.

## Initial Dimensions

- Region: US, INTERNATIONAL
- Market-cap buckets: MEGA, LARGE, MID, SMALL, MICRO

## Mapping Principles

- Mappings are explicit and configuration-driven.
- Placeholders are permitted in early waypoints but must be versioned.
- Benchmark selection must preserve comparability for each security universe.

## Historical Integrity

- Benchmark definitions are time-aware and append-oriented.
- Mapping changes are captured as new effective records, not overwrites.

## Future Expansion

- Add fixed-income benchmark families.
- Add sector and style overlays.
- Add region-specific benchmark hierarchies for international expansion.
