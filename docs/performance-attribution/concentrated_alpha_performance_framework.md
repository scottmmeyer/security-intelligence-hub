# CONCENTRATED ALPHA PERFORMANCE FRAMEWORK
**Date:** 2026-06-12
**Purpose:** Define how SIH should evaluate whether Concentrated Alpha created value

## Goal

Answer the question:
- Did the portfolio's high-conviction decisions create alpha?

This is a display-only performance interpretation layer. It does not change recommendations, rankings, or scoring.

## Measurement Layers

### 1) Security contribution layer
Measure what each holding contributed to portfolio return.

Core metric:
- Contribution % = Weight × Security Return

Use this to identify:
- top contributors
- top detractors
- concentrated winners
- concentrated losses

### 2) Decision lineage layer
Tie contribution back to SIH decisions.

Track whether the position was:
- recommended by SIH
- high conviction / anchor allocation
- a PAP deployment action
- a reduction/trim candidate that was retained
- a reduction/trim candidate that was exited

This answers whether SIH's conviction engine helped or hurt results.

### 3) Outcome layer
Measure whether the decision was directionally correct.

Examples:
- Bought VRT and it contributed positively over the next month
- Kept TSM and it remained a contributor
- Held PRIM and it became a detractor
- Reduced KGC before further deterioration

### 4) Benchmark-relative layer
Measure whether the concentrated style created excess return.

Use:
- Portfolio return
- Benchmark return
- Alpha = Portfolio - Benchmark

Benchmarks:
- S&P 500 as the default operator benchmark
- Total Market as a secondary reference
- ACWI for international context

### 5) Conviction-quality layer
Measure whether higher-conviction positions actually outperformed lower-conviction ones.

Framework:
- group holdings by conviction tier
- compare average contribution and subsequent return by tier
- compare high-conviction vs low-conviction contribution rates

Questions answered:
- Did top-ranked holdings outperform the rest?
- Did conviction anchors carry the portfolio?
- Did reduction decisions avoid future drag?

## Recommended Scorecard

For each review period, show:
- contribution by conviction tier
- contribution by recommendation class
- hit rate of buys
- hit rate of holds
- hit rate of reductions
- alpha versus benchmark

## What this framework should not do

- It should not alter CW-DAS.
- It should not change recommendation ranking.
- It should not retroactively rewrite decision history.
- It should not become a trade signal.

## Recommended Interpretation

Concentrated Alpha created value when:
- high-conviction positions contributed more than they detracted
- SIH-recommended positions beat the benchmark on a contribution basis
- exited or reduced positions stopped subtracting from returns
- conviction tiers show persistent positive contribution over time

If the opposite happens, SIH should surface that honestly as a decision-quality problem, not hide it.
